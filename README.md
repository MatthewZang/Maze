# Maze Game

A challenging maze game built with HTML5 Canvas and JavaScript. Navigate through increasingly complex mazes while racing against time!

Play the game here: [Maze Game](https://matthewzang.github.io/Maze/)

## Features

- Two difficulty modes: Easy and Hard
- 20 progressively challenging levels
- Time tracking and best time records
- Dynamic maze generation
- Smooth animations
- Responsive controls

## How to Play

1. Choose your difficulty level (Easy or Hard)
2. Use arrow keys to navigate through the maze
3. Reach the red exit square to complete each level
4. Try to beat your best time!

### Controls
- ↑: Move Up
- ↓: Move Down
- ←: Move Left
- →: Move Right

## Development

The game is built using vanilla JavaScript and HTML5 Canvas. No external dependencies required!

### Files
- `index.html`: Main HTML file
- `game.js`: Game logic and rendering
- `README.md`: Documentation
